# 📊 Sales Dashboard (2020–2022) - Power BI Project

This Power BI project presents a comprehensive **Sales Dashboard** for the years **2020 to 2022**, designed to provide insights into sales performance, revenue trends, and key business metrics.

---

## 📝 Project Overview

The Sales Dashboard offers a visual and interactive analysis of sales data over a three-year period. It helps stakeholders quickly identify patterns, track KPIs, and make data-driven decisions.

---

## 📌 Features

- 📅 Year-wise sales overview (2020, 2021, 2022)
- 💰 Monthly and quarterly revenue trends
- 📍 Region and state-wise performance
- 🛍️ Product category and sub-category breakdown
- 📈 Top performing products/customers
- 📉 Sales vs Target visual comparison
- 📊 Interactive slicers and filters
